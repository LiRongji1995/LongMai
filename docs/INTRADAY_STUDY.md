# 盘中分时研究 — 预注册

写于 2026-11-10，在看任何分时结果之前。代码：`sf/intraday.py`（数据格式 `SF_INTRADAY_V1`，特征 `SF_INTRADAY_FEATURES_V1`）。

## 目的

日线能找出更可能走出来的股票，但同一批股票的大面也更多；区分两者的信息在盘中。本研究回答三个问题，
全部只用收盘后可知的盘中事实，结果按不设买入价的命中率衡量（与 `sf evaluate` 相同）：

1. **板块内谁先封板**：同一热门板块里最先封板的股票，次日是否比后封的更强？
2. **封板质量**：一字、秒板、早盘封、午后封、回封、炸板，次日表现是否有稳定差异？
3. **拥挤代价**：清单类股票（涨停、连板）次日开盘时已经被定价了多少？有多少根本买不到？

## 数据

- 来源：东方财富 1 分钟线（每只股票一次请求返回最近 5 个交易日，每天 241 根）。只保留最近约 5 天，
  所以必须每天收盘后抓取；漏掉的日子无法补。
- 每天抓取的股票（只用当天收盘后已知的信息决定）：当天沪深 A 股中收盘涨停或盘中触及涨停的全部股票，
  加上当天作为目标日或观察日的已保存清单里的股票。抓取名单和原因存于 `intraday/universe/<日期>.parquet`。
- 每次请求的原始返回原样存于 `intraday/raw/`；抓取失败、数据不全（不足 241 根）、当天无数据的股票都写进
  `intraday/capture/<日期>.json`，不会悄悄少算。
- 补充（2026-11-11，只涉及存储，不改假设、特征和判定）：当晚生成的清单在抓取之后才存在，它的股票按上面的定义本来
  就属于当天的抓取名单（观察日清单）。生成清单时补抓这些股票，存于 `intraday/supplement/{minute,universe,capture}/<日期>/`，
  原文件不改；读取某天的分钟线时合并主文件和补抓文件。特征缓存文件名带补抓次数（`<日期>+s<n>.parquet`）。
- 单位：成交量为股（源数据是手，×100）；成交额为元；时间为北京时间；分钟序号 0 = 09:30（含集合竞价），
  120 = 11:30，240 = 15:00。源数据只有最新一天有开盘价，其余为缺失（不是 0）。

## 特征定义（`SF_INTRADAY_FEATURES_V1`）

| 特征 | 定义 |
|---|---|
| `first_touch_min` / `first_seal_min` | 第一根最高价触及涨停 / 收盘价在涨停的分钟序号；从未发生为缺失 |
| `last_seal_min` | 收盘封住时，最后一段连续封板开始的分钟序号 |
| `reopen_count` | 首次封板后，从封住到打开的次数 |
| `sealed_share` | 首次封板之后，收盘价在涨停的分钟占比 |
| `seal_type` | 一字（全天最低价在涨停）、回封（打开过但收盘封住）、秒板（第 5 分钟内封住）、早盘封（11:30 前）、午后封、炸板（触及但未封住） |
| `close_vs_vwap` | 收盘价相对全天成交均价 |
| `above_vwap_share` | 收盘价高于当时均价线的分钟占比 |
| `auction_vol_share` / `open30_vol_share` / `tail30_vol_share` | 09:30 那根 / 前 30 分钟 / 最后 30 分钟成交量占全天比例 |
| `fade_from_high` | （全天最高价 − 收盘价）/ 前收盘价 |
| 板块内封板顺序 `lead_rank` | 当天收盘封住的股票，在它所属的、当天封板家数最多的热门板块（≥ 3 只封住）里，按 `first_seal_min` 排第几 |

## 结果变量（与 `sf/evaluate.py` 相同，不设买入价）

`lu1` 次日涨停；`bigloss1` 次日大面（最低 ≤ −7% 或收盘 ≤ −5%，相对当天收盘）；`out5` 5 日内 ≥ 2 个涨停或最高 +20%。
后续交易日尚未入库时为待定，不算未命中。

拥挤代价（问题 3）只用日线、可以用全部历史：次日开盘缺口 = 次日开盘价 / 当天收盘价 − 1；买不到 = 次日一字涨停；
按连板高度（首板、2 板、3 板、4 板以上）分组，报告缺口均值、买不到比例、3 日最高涨幅均值，以及缺口占 3 日最高涨幅的
中位比例（只算 3 日最高涨幅 > 5% 的样本）。

## 假设与判定（事先写定）

- **H1 先封者更强**：`lead_rank` = 1 的 `lu1` 高于 `lead_rank` ≥ 2，且 `bigloss1` 不更高。
- **H2 封板质量**：`lu1` 排序为 一字/秒板 > 早盘封 > 午后封、回封 > 炸板；`bigloss1` 大致相反。
- **H3 拥挤代价随高度上升**：缺口和买不到比例随连板高度上升。

判定规则：分时数据全部是前向样本（从 2026-11 开始积累），没有被看过的历史，因此是干净的检验。
- 积累到 **40 个交易日之前**，只报告描述统计，不下结论、不改规则。
- 满 40 个交易日后，按上面的方向和定义检验一次；差异需在前后两个 20 日子段方向一致才算成立。
- 阈值（5 分钟、11:30、≥ 3 只封住）不在看结果之后调整。
- 任何结论如要进入清单规则，都作为新的策略版本，重新开始前向检验。

问题 3 用的是日线历史（已在以前的研究中被看过），只作描述，不作检验。
