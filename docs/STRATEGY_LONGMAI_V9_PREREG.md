# 龙脉 V9（`SF_LONGMAI_V9`）— 形态细分 · 预注册

写于 2026-11-11，在看任何形态细分结果之前。**状态：使用者已于 2026-11-11 确认，内容不改。** 本文件随检验代码一起提交；
“判定细则”一节在写代码时、跑任何结果之前补写，只把原文没写清的地方写定。结果追加在文末。V7 继续是正式清单。

## 为什么做

V7 的三个选股形态（`sf/strategy.py`：强势启动 `STRONG_START`、强势延续 `STRONG_CONTINUATION`、首次回调
`FIRST_PULLBACK`）是从旧 R2 流水线继承来的，阈值没有按短线命中率单独校准过。结构上的不足（2026-11-11 讨论）：

- 首次回调：不看回调日是缩量还是放量，不看盘中有没有大面，不分前面的上涨有没有涨停，不看回踩到哪条均线；
- 强势启动：“突破”只比前 5 天，不分涨停启动和普通大阳，不看股价所处位置；
- 强势延续：没有“加速过度 / 放量见顶”的识别，成交额门槛只有 5000 万；
- 三个形态共用的“收盘在 20 日线上且 20 日线向上”对 5 日涨 15–20% 的股票几乎不起作用。

这些不足来自经验说法，不是数据。本预注册把每一条翻成一个事先写定阈值的二分标记，用历史检验它是否真的区分结果。

## 作用范围

在 V7 中，形态只决定 **“观察”组**（主线以外符合形态的股票）和角色里的形态标签；主线龙头与连板梯队的入选不依赖形态。
因此 V9 只改形态的入选条件，主线龙头、连板梯队、高波动的规则不变。连板梯队的封板质量属于盘中分时研究
（`docs/INTRADAY_STUDY.md`），不在本版本内。

## 检验样本

- 每个观察日 T：所有满足 V7 合格条件（主板、非 ST、上市满 60 个交易日、当天正常交易、R2 换手门槛）且满足某一形态的股票，
  按形态分别统计。不是只统计清单上显示的前 10 只，以免显示上限影响结论。
- 一只股票同一天满足多个形态，在每个形态里各算一次。
- 日线 2022-03-17 起（前 60 个交易日为预热）。

## 结果变量（与 `sf evaluate` 相同，不设买入价，从 T 收盘起）

`lu1`（次日涨停）、`max3`（3 日最高涨幅）、`out5`（5 日内 ≥ 2 个涨停或最高 +20%）、`bigloss1`（次日最低 ≤ −7% 或收盘 ≤ −5%）。
主要看 `out5`（走出来）和 `bigloss1`（大面）；`lu1`、`max3` 只报告。后续交易日未入库记为待定，不算未命中。

## 候选细分（全部只用 T 收盘时已知的日线；阈值事先写定，看结果后不改）

记号：`amt` 成交额，`clv` =（收盘 − 最低）/（最高 − 最低），`MAk` 为 k 日均线（复权收盘价），涨跌幅相对前收盘价。

| 编号 | 形态 | 标记（“是”的定义） | 预期方向 |
|---|---|---|---|
| P1 | 首次回调 | 缩量：T 日成交额 ≤ 前 3 个上涨日平均成交额 × 0.8 | 是 → `out5` 更高 |
| P2 | 首次回调 | 盘中大面：T 日最低价 ≤ 前收盘 × (1 − 7%) | 是 → `out5` 更低、`bigloss1` 更高 |
| P3 | 首次回调 | 前段有涨停：前 3 个上涨日中至少 1 天收盘涨停 | 是 → `out5` 更高 |
| P4 | 首次回调 | 守住 5 日线：T 日最低价 ≥ MA5（T 日） | 是 → `out5` 更高 |
| S1 | 强势启动 | 长平台突破：T 收盘 > 前 20 个交易日最高收盘价 | 是 → `out5` 更高 |
| S2 | 强势启动 | 涨停启动：T 日收盘涨停且不是一字 | 是 → `out5` 更高 |
| S3 | 强势启动 | 低位：T 收盘 / 前 60 个交易日最低收盘价 ≤ 1.3 | 是 → `out5` 更高 |
| C1 | 强势延续 | 放量异常：T 日换手率 ≥ 前 5 日平均换手率 × 2 | 是 → `bigloss1` 更高 |
| C2 | 强势延续 | 加速过度：5 日涨幅 ≥ 40% | 是 → `bigloss1` 更高 |
| C3 | 强势延续 | 流动性：T 日成交额 ≥ 2 亿 | 是 → `out5` 更高、`bigloss1` 不更高 |

一共 10 个标记，不再增加；看到结果后想到的新标记，属于下一个版本。

## 分段（与 `sf evaluate` 相同）

- train：观察日 < 2025-02-06
- test1：2025-02-06 ≤ 观察日 < 2025-12-17
- test2：观察日 ≥ 2025-12-17
- 前向记录：V9 代码冻结后的第一个交易日起，与 V7 并行

样本的干净程度：2025–2026 的日线在 V1–V8 的研究中都被看过；2022-03 至 2025-02 的日线在 V8 中看过，但用于另一套特征和考卷。
这 10 个标记在任何分段上都没有看过结果。两个测试段不是完全干净的样本，**前向记录才是决定性的检验**。

## 判定规则（事先写定）

**单个标记是否采用。** 比较同一形态内“是”与“否”两组，三段都要满足：

1. 样本量：train 每组 ≥ 200 个股票日，test1、test2 每组 ≥ 50；不足则该标记判为“样本不足，不采用”。
2. train：主要指标朝预期方向的差 ≥ 5 个百分点（`out5` 或 `bigloss1`，按上表）；另一个指标不朝反方向恶化超过 2 个百分点。
3. test1 和 test2：方向与 train 相同，且差的大小 ≥ train 的一半。

10 个标记同时检验，偶然通过的可能不小；要求两个测试段都同向复现就是为了控制这一点。所有 10 个标记的结果全部报告，
不只报告通过的。

**采用后的用法（事先写定）：** 预期“是更好”的标记通过 → 该形态改为必须满足它；预期“是更差”的标记通过 → 满足它的股票
从该形态中去掉。形态的其他阈值不变。

**V9 是否进入前向记录：** 至少 1 个标记被采用，且用采用后的规则重放观察组，在 test1 与 test2 中观察组的 `out5`
都不低于 V7、`bigloss1` 都不高于 V7。否则如实报告为否定结果，V7 不变。

**前向记录：** 与 V7 并行至少 60 个交易日；V9 观察组 `out5` 不低于 V7 且 `bigloss1` 不高于 V7，才替换 V7 的观察组规则。

## 判定细则（写代码时补写，先于任何结果）

- **主要指标**取上表“预期方向”里写在前面的那个：P1、P3、P4、S1、S2、S3、C3 为 `out5` 更高；P2 为 `out5` 更低；
  C1、C2 为 `bigloss1` 更高。另一个指标的“反方向恶化”：主要指标为 `out5` 更高时，指 `bigloss1`（是 − 否）> +2 个百分点；
  P2 指 `bigloss1`（是 − 否）< −2 个百分点；C1、C2 指 `out5`（是 − 否）> +2 个百分点。
- **样本量**按该段 `out5` 已有结果的股票日计数（待定的不算）。
- **标记未知**（所需日线缺失）的股票日不进入该标记的比较，未知数量单独报告；采用后，“必须满足”的标记未知时视为不满足，
  “去掉”的标记未知时保留。
- **重放的观察组**：每天满足 V7 合格条件和形态（R2 选中）、但不是主线龙头、也不是主板 2 板及以上的全部股票，
  不受清单只显示前 10 只的限制；主线龙头按 V7 规则逐日重算（历史上不使用龙虎榜席位，与 V8 检验相同）。
- 观察日从第 61 个已存交易日起（前 60 个为预热），最后一个已存交易日不重放（结果全部待定）。

## 稳健性邻域（只报告，不用于挑选）

P1 的系数 0.7 / 0.9；S1 的 10 / 60 日；S3 的 1.2 / 1.5；C2 的 30% / 50%；C3 的 1 亿 / 3 亿。
邻域只用来判断结论是否依赖某个恰好的阈值；不会因为某个邻域值更好而改用它。

判定：2 个标记被采用；但 V9 观察组的 `bigloss1` 在 test1、test2 都高于 V7（+0.8、+0.6 个百分点），不满足
“`bigloss1` 都不高于 V7”。按预注册：**V9 不进入前向记录，V7 仍是正式清单。** 否定结果如实保留。

观察（描述，不据此改规则；任何据此的改动都是新版本，需重新预注册）：

- 首次回调在全历史里很少（train 约 1557 个股票日），4 个回调标记里 3 个因一组样本不足无法判定。
- 几条常见经验和数据方向相反：缩量回调的 `out5` 更低（但大面也低得多）；低位启动、成交额大的强势延续 `out5` 更低；
  加速过度（5 日 ≥ 40%）的 `out5` 和大面都高得多，是高波动而不是单纯的见顶。
- 最稳定的两个区分是“涨停启动比普通大阳更容易走出来”（三段 +7.6 ~ +10.4）和“放量异常的延续股次日大面更多”
  （三段 +7.6 ~ +8.9）。合在一起提高了走出来的比例，却没有降低大面：这正是 V7 的“走出来”和“大面”同涨同跌的老问题
  （见盘中分时研究的目的一节）。
