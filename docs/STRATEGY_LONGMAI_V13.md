# 龙脉 V13：放量风险提示（使用者决定）

- **版本**：`SF_LONGMAI_V13` = V12（V9 选股 + 成交额门槛）+ 本文的放量提示。
- **决定**：2026-11-12 由使用者提出。起因是福建水泥观察日成交 16.9 亿，是前几天的好几倍，清单却没有任何提示。
  原有的“放量分歧”只查主线龙头和连板梯队、只看换手率，而且当天封住涨停的不提示。

## 规则

清单里每一只股票（所有分组，封没封涨停都算）：观察日成交额 ≥ 前 5 个交易日成交额均值的 3 倍，就在“风险提示”最前面写：

> 放量：成交额 X 亿，为前 5 日均值 Y 亿的 N 倍

- 前 5 日里有成交额的日子少于 3 天（新股、停牌复牌等）时，写“前5日成交额缺失，放量未检查”，不当作没放量。
- 只是提示，**不改分组、不改排序、不占仓位名额**；原有的“放量分歧”（拥挤）规则不变。
- 3 倍是按使用者“好几倍”的说法取的整数，没有回测；效果看之后的复盘。

## 参数

| 参数 | 值 |
|---|---|
| 倍数 | 3 |
| 对比的天数 | 前 5 个交易日 |
| 最少有效天数 | 3 |
