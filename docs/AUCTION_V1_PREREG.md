## 1. 要回答的问题

9:25 竞价结束后，能不能根据竞价结果，把盘前清单里的股票分成「竞价确认 / 中性 / 竞价否定」，并且分出来的结果在
历史上站得住？

竞价层**不加股票、不改分组、不改排序**，只给清单里已有的股票加一个竞价标签。系统仍然不交易，标签只是参考。

## 2. 决策时点和可用数据

- 决策时点：交易日 T 的 9:25。
- 可用数据：
  - T 日的盘前清单，由 T-1 收盘数据生成；
  - T 日的竞价结果。
- 历史上能拿到的竞价信息只有**开盘价**（日线的 open）。由此得到：
  - 竞价缺口 g = T 日开盘价 / T 日昨收 − 1；
  - 是否涨停开（开盘价 ≥ 涨停价）。
- 竞价成交额、未匹配量历史上拿不到。`sf auction` 从 2026-11-12 起每天保存快照；满 40 个交易日后另做研究，作为新版本。
  本次检验不用这两项。

## 3. 角色

按 V9 清单的规则在历史上逐日重放（与 V9 检验相同，不用席位数据）：

| 角色 | 对应清单分组 |
|---|---|
| leader | 主线龙头 + 高波动 |
| ladder | 连板梯队（主板 2 板及以上，且不是主线龙头） |
| observe | 观察（R2 选中，不是主线龙头，也不在连板梯队） |

历史重放包含每天全部入选股票，不受清单显示数量的限制。

## 4. 标签

每个角色各有两个分界点：取 **train 段**（2025-02-06 之前）该角色「可买」股票竞价缺口的 1/3 分位和 2/3 分位。
「可买」指竞价缺口已知，且不是涨停开。分界点只用 train 段计算，测试段的数据不参与。

| 标签 | 条件 |
|---|---|
| 涨停开 | 开盘价 ≥ 涨停价（可能买不到，单独一类，不参与确认 / 否定比较） |
| 竞价缺失 | T 日没有成交的日线（停牌或缺数据），记为缺失，不算任何一类 |
| 竞价确认 | g > 2/3 分位 |
| 竞价否定 | g < 1/3 分位 |
| 竞价中性 | 其余 |

## 5. 结果指标（以 T 日开盘价为参照）

9:25 时已知的最后价格是开盘价。如果仍以昨收为参照，高开本身就会被算成「涨了」，竞价确认组会被凭空抬高。
所以本检验的指标都以 T 日开盘价为参照。指标的计算方式与现有的不设买入价命中率相同，不是开盘买入的盈亏回测。

| 指标 | 定义 |
|---|---|
| a_out5「走出来」 | T 至 T+4 共 5 个交易日内，涨停 ≥ 2 次，或最高价较 T 日开盘价 ≥ +20% |
| a_bigloss「当日大面」 | T 日最低价 ≤ 开盘价 × 0.93，或收盘价 ≤ 开盘价 × 0.95 |
| a_lu | T 日收盘涨停 |
| a_max3 | T 至 T+2 的最高价相对 T 日开盘价的涨幅 |

以昨收为参照的 lu1、out5、bigloss1 也一并计算，只作描述。尚未出结果的样本记为待定，不算失败。

分段与 `sf evaluate` 相同：

| 段 | 时间范围 |
|---|---|
| train | 2025-02-06 之前 |
| test1 | 2025-02-06 ~ 2025-12-17 |
| test2 | 2025-12-17 之后 |

## 6. 判定规则（每个角色分别判定）

比较对象是同一角色、同一段里的「可买」全体，即确认、中性、否定三类合起来。

**竞价确认标签采用的条件**：三段都同时满足以下几条。
- 确认组的 a_out5 比可买全体高至少 2 个百分点；
- 确认组的 a_bigloss 增幅不超过 a_out5 增幅的一半，且最多 +2 个百分点。这是使用者 2026-11-11 定的取舍规则。
- 样本量（a_out5 已有结果的行数）：确认组 train 段 ≥ 200，每个测试段 ≥ 50。

**竞价否定标签采用的条件**：三段都满足以下两条中的至少一条，样本量要求与确认标签相同。
- 否定组的 a_out5 比可买全体低至少 2 个百分点；
- 否定组的 a_bigloss 比可买全体高至少 2 个百分点。

**稳健性邻域**：用 1/4 和 3/4 分位重算一遍。结果只报告，不用于选择。

**采用后**：
- 把采用的分界点写进 `auction.ADOPTED`，注明检验的时间戳。`sf auction` 从此对该角色显示被采用的标签，没有被采用的标签显示为中性。
- 从采用当天起逐日保存快照，作为前向记录。满 60 个有结果的交易日后，按同一规则复核。

**没有一个标签被采用时**：竞价层保持只描述，结论如实写在文末。

## 7. 已知局限（事先写明）

- 两个测试段在 V1–V9 中都看过，不是干净样本。
- 板块成分有前视偏差，与 V9 检验相同。
- 历史重放不用席位，所以主线龙头和高波动合为一个角色。
- 开盘缺口和结果有机械联系：例如高开接近涨停时，当日再涨的空间小。这正是需要检验的内容，不做修正。
- 竞价额和未匹配量没有历史数据，本版本不判断「竞价放量」「封单大小」。
- 这只是对历史命中率的统计，不是投资建议；买卖由人在盘中决定。

**判定**

| 角色 | 竞价确认 | 竞价否定 |
|---|---|---|
| 主线龙头 / 高波动 | 不采用：train 段走出来 +8.5，大面 +12.8 | **采用**：三段走出来 −4.9 / −6.0 / −5.7 |
| 连板梯队 | 不采用：train 段走出来 +6.5，大面 +11.6 | **采用**：三段走出来 −5.1 / −6.8 / −4.2 |
| 观察 | 不采用：train 段走出来 +5.0，大面 +8.1 | 不采用：test1 段走出来 −0.8，大面 −2.7 |

表中数字是相对同角色可买全体的差，单位为百分点。稳健性邻域（1/4、3/4 分位）的结论与此相同。

**解读**（只描述统计，不是投资建议）：
- **高开（竞价确认）**：当日涨停和 5 日走出来都明显更多，但开盘后当日大面多得更多。主线龙头三段大面分别为 41.7% / 36.0% / 32.6%，可买全体为 28.9% / 27.9% / 25.4%。按使用者的取舍规则不采用。
- **低开（竞价否定）**：5 日走出来少约 4–7 个百分点。但开盘后当日大面反而更少：主线龙头 16.9% / 20.8% / 18.0%，可买全体 28.9% / 27.9% / 25.4%。所以“竞价否定”的含义是“不太会走出来”，**不是**“更危险”。
- **涨停开**：主线龙头和连板梯队当日涨停约 79%–84%，5 日走出来约 56%–63%，开盘后当日大面约 20%–27%。这一类只作描述。

**采用后的做法**：`auction.ADOPTED` 写入主线龙头和连板梯队的分界点，只启用竞价否定标签。`sf auction` 对这两个角色显示“竞价否定”，其余显示为中性或涨停开；观察组只描述。从 2026-11-12 起保存的快照作为前向记录，满 60 个有结果的交易日后按同一规则复核。

两个测试段在之前的版本中都看过，不是干净样本。
