# 拥挤度研究 — 预注册

在第一次运行之前写成。指标代码：`sf/crowding.py`。

## 问题

短线资金（占全市场成交额的比例、增速、在主线中的集中度）是否存在某个水平，超过之后不再有增量资金进来，
接力交易和主线龙头就不再赚钱？

## 指标（都在观察日收盘后可知）

市场层面：`spec_share`（近 5 个交易日涨停过的股票成交额 / 全市场成交额）、`hot_turn_share`（换手率 ≥ 15% 的
股票成交额 / 全市场成交额）、它们的 5 日变化、`amount_ratio20`（全市场成交额 / 前 20 日均值）、
`top3_share`（前 3 条主线板块成分股成交额 / 全市场成交额），以及 `spec_pct250`：`spec_share` 在 250 个交易日
滚动窗口中的分位（不受市场阶段影响的版本）。
题材层面（龙头所在的主线板块）：`share`、`share_pct60`、`share_chg5`。
个股层面：`leader_theme_share` = 龙头成交额 / 其板块成交额。

## 结果变量

1. 接力篮子：当日主板涨停股从次日开盘到再次日开盘的收益（按天）。
2. 接力 5 日：之后 5 个观察日接力篮子的平均值（资金是否持续赚钱？）。
3. 龙头交易：每一个 V1 龙头信号（主线排名 ≤ 3，龙头排名 ≤ 2，成交额排名 ≤ 30），不加情绪/监管闸门、
   否决或仓位限制，按 V1 的买卖规则模拟，成本 0.15%。按天对当日所有信号取平均。

## 方法

分段：观察日按 60/20/20 分为 train / test1 / test2。每个指标的五分位边界只在 train 上计算，原样用于测试段。
只有当一个指标在三个分段中都满足“最高五分位的结果差于中间三个五分位”，并且 train 选出的方向在两个测试段都成立时，
才称它为拥挤信号。阈值报告为 train 的五分位边界；不在测试数据上调任何参数。

注意：测试段在之前的研究（情绪、V1–V3）中已被看过，并不干净。这里产生的任何规则都会成为新的策略版本，
重新开始自己的前向检验。

## 结果（第一次运行，2026-11-10）

数据：1128 个交易日（2022-03 至 2026-11），分界 2025-02-06 和 2025-12-17。435 个 V1 龙头信号，
237 笔已平仓交易（145 / 49 / 43）；3190 个主线板块日（1915 / 639 / 636）。
脚本和面板：`stockfish-data/research/crowdscripts/`、`research/crowding_*.parquet`。

市场层面——各分段最高五分位减中间三个五分位（train / test1 / test2）：

| 指标 | 次日接力 | 龙头交易 |
|---|---|---|
| spec_share（原值） | −0.00 / −0.24 / +0.11 % | +0.3 / −1.7 / +9.4 % |
| spec_pct250 | −0.23 / −0.12 / −0.15 %（t ≈ −0.5；符合符号规则，但不显著） | −0.3 / −8.2（n=2）/ +7.4 % |
| hot_turn_share | −0.02 / −0.39 / +0.00 % | 方向不一 |
| spec_share_chg5、hot_turn_chg5 | 符号不一 | 方向不一 |
| amount_ratio20 | +0.59 / +0.08 / +0.05 %（钱越多越好，而不是越差） | 方向不一 |
| top3_share | +0.25 / +0.21 / +0.17 %（越集中越好） | 符合符号规则；train 差值 −0.04 % |

结论：**不存在市场层面的拥挤阈值。** 短线资金占比的水平随市场阶段漂移（原值跨年不可比）；它的分位只以极小、
不显著的差距通过符号规则；龙头交易每格只有 2–34 笔，波动 ±10%。总成交额越高、前 3 条主线越集中，次日接力
反而*越好*，与拥挤假设相反。5/10 日接力窗口互相重叠，t 值被高估，因此不采用。

题材层面——主线板块日，结果“退潮” = 两个交易日后的涨停数低于当日的 34%：

| share_pct60 五分位（train 边界 .53 / .80 / .93 / .98） | Q1 | Q2 | Q3 | Q4 | Q5 |
|---|---|---|---|---|---|
| train 退潮 % | 16.5 | 20.8 | 18.4 | 18.7 | **33.1** |
| test1 退潮 % | 13.0 | 15.2 | 14.5 | 17.5 | **22.6** |
| test2 退潮 % | 20.0 | 18.3 | 23.0 | 21.7 | **33.9** |

在涨停数分桶（3–4、5–7、8–12、13+）内，最高五分位在 12 个“分段 × 分桶”格子中有 11 个退潮更多，所以这不只是
“今天涨停多，之后自然回落”。`share_chg5` 方向相同但更弱。`share` 原值方向相反（大板块退潮更少）。板块涨停股之后
3 个交易日的收益没有一致差异（train −1.23 vs −1.22 %，test1 −0.70 vs −0.87 %，test2 −2.23 vs −0.40 %），
按它拆分的 V1 龙头交易也不一致。

用法：盘前概况会标出成交占比处于 60 日最高位的主线（`crowding.HOT_PCT` = 0.983），并把市场短线资金占比作为
背景打印。两者都不改变任何交易规则，也不改变策略版本。基于题材退潮的规则（例如板块成交占比处于高位时退出或跳过）
将是一个新的、预注册的版本，有自己的前向检验。
