# ADR 0001: Provisional initial architecture

Status: proposed pending Phase 1 audit. Choose liquid US equities/ETFs and medium/low frequency to bound data/execution complexity; evaluate LEAN as the research/backtest base; evaluate Alpaca as first broker/data candidate; use Python for strategies/services; require Paper Trading before live; and exclude LLMs from the real-time order path. These are hypotheses, not validated integrations or production endorsements.
