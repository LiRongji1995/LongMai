# Glossary

- **Raw / Clean / Adjusted / Features:** immutable source, normalized rebuildable, corporate-action-adjusted, and derived data layers.
- **Point-in-time:** using only information available at the decision timestamp.
- **OMS:** order-management system and its auditable lifecycle state.
- **Kill switch:** independent global control that blocks risk opening/order submission.
- **Paper Trading:** broker simulation, not proof of executable live performance.
- **Manifest:** versioned provenance/checksum record for data or a run.
