# 预注册：龙脉 V10 候选——小成交额与一字板（`SF_LONGMAI_V10`）

状态：**使用者已于 2026-11-12 确认，选定组规则 B**（`quality.GROUP_RULE = "B"`）。确认和选择时尚未运行任何检验。
运行前记录了本文件（第 8 节为占位）和 `stock-fish/sf/quality.py` 的 sha256，记录写在第 8 节。运行后不改规则、不改阈值，
结果不论好坏都如实写进文末。

## 1. 起因

使用者在 2026-11-12 盘中观察到，成交额小的票反馈很差，例子有：
- 达意隆：一字 2 板，成交 0.4 亿，今天涨停开后炸板，跌破开盘价超过 11%；
- 瀛通通讯：一字 2 板，成交 0.4 亿，今天竞价 −8.2%；
- 海源复材：观察组，成交 3.1 亿，今天竞价 −2.1%。

使用者的印象是：低位、小成交额的连板晋级率极低，一字板上来的尤其明显。

检验数据截至 2026-11-11，不包含引出这个想法的 11-12 这几个例子。

## 2. 范围

按 V9 清单规则逐日重放（与竞价层 V1 的重放相同，包含每天全部入选股票），分三个角色**各自判定**：

| 角色 | 对应清单分组 | 主要指标 |
|---|---|---|
| leader | 主线龙头 + 高波动 | lu1 次日晋级（次日涨停） |
| ladder | 连板梯队 | lu1 次日晋级（次日涨停） |
| observe | 观察 | out5 走出来 |

## 3. 标记（只用观察日 t 收盘前的日线；输入缺失时标记为未知，不当作“否”）

| 标记 | 定义 | 稳健性邻域（只报告，不用于选择） |
|---|---|---|
| L1 小成交额 | t 日成交额 < 1 亿 | 0.5 亿、2 亿、3 亿 |
| L2 一字板 | t 日一字涨停 | — |
| L3 低位 | t 日复权收盘价 / t 日前 60 个交易日的最低复权收盘价 ≤ 1.5 | 1.4、1.6 |
| L12 | L1 且 L2 | — |
| L13 | L1 且 L3 | — |

## 4. 指标（以 t 日收盘为参照，不设买入价）

| 指标 | 定义 |
|---|---|
| lu1 | t+1 日收盘涨停 |
| out5 | t+1 至 t+5 日内涨停 ≥ 2 次，或最高价较 t 日收盘价 ≥ +20% |
| bigloss1 | t+1 日最低价 ≤ −7%，或收盘价 ≤ −5%（相对 t 日收盘） |
| max3 | t+1 至 t+3 日的最高涨幅 |

另外报告两项，只作描述：t+1 日是否涨停开；t+1 日开盘后是否大面（最低价 ≤ 开盘价 × 0.93，或收盘价 ≤ 开盘价 × 0.95）。

分段与 `sf evaluate` 相同：

| 段 | 时间范围 |
|---|---|
| train | 2025-02-06 之前 |
| test1 | 2025-02-06 ~ 2025-12-17 |
| test2 | 2025-12-17 之后 |

## 5. 单个标记是否成立（按角色分别判断）

以下条件全部满足，标记才算成立：

- **样本量**：标记为“是”的样本，train 段 ≥ 100，每个测试段 ≥ 30；标记为“否”的样本，每段 ≥ 30。样本量指主要指标已有结果的行数。小成交额连板本来就少，所以门槛比 V9 的 200 / 50 低。
- **train 段**：标记组的主要指标比非标记组低至少 5 个百分点。
- **两个测试段**：标记组都比非标记组低，且差距至少是 train 段差距的一半。

## 6. 改动是否采用（按角色分别判断）

**改动内容**：在某个角色里，任一成立的标记为“是”的股票，移出该角色。具体去向：
- 移到新标签“小成交额/一字（只观察）”，仍显示在清单里，但不再是该角色的候选；
- 标记未知的股票保留在原分组。

**比较方式**：该角色在 V10 的规则下（移出之后）与 V9（全部保留）比较，三段都要满足使用者选定的组规则：

| 组规则 | 条件 |
|---|---|
| **A**（AGENTS.md 的默认取舍规则） | 走出来至少 +2 个百分点；大面增幅不超过走出来增幅的一半，且最多 +2 个百分点 |
| **B**（A 的“降风险”镜像） | 次日大面至少 −2 个百分点；走出来的下降不超过大面降幅的一半 |

**为什么要选**：移出一小部分股票，往往很难让整组走出来提高 2 个百分点。如果这些股票的主要问题是次日大阴线，规则 A 很可能判否，即使移出它们确实降低了风险。规则 B 正是检验“少吃大面、又不明显少走出来”。

**这个选择必须在看结果之前做出**，选定后写进 `quality.GROUP_RULE`。

**结论**：
- 一个角色只有在至少一个标记成立、且三段都满足组规则时，才采用改动。采用的改动构成 V10 候选。
- 是否替换 V9 成为正式清单，由使用者决定；采用后从当天起记前向记录。
- 没有任何角色采用改动时，V9 保持不变。现有的风险提示照旧（“一字板（今日几乎无换手）”“流动性差”）。

## 7. 已知局限

- 两个测试段在 V1–V9 中都看过，不是干净样本。
- 板块成分有前视偏差；历史重放不用席位数据。这两点与 V9 检验相同。
- 成交额的阈值是绝对值，没有按市场整体成交规模调整，4 年里市场成交变化很大。邻域（0.5 亿 ~ 3 亿）只用来看结论是否稳定。
- 一字板次日常常买不到。这里的指标都不设买入价，只回答“有没有晋级、有没有大阴线”，不代表能否成交。
- 这是历史命中率统计，不是投资建议；买卖由人决定。

**事后描述（不在预注册之内，不作结论）**：把连板梯队按“小额一字”和次日是否涨停开再分一层，可以看到使用者说的“看板就是大阴线”出现在哪里：
