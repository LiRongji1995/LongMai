# 龙脉 V14：成交额门槛加“或换手率 ≥ 10%”（使用者决定）

- **版本**：`SF_LONGMAI_V14` = V13（V9 选股 + V12 成交额门槛 + V13 放量提示），只改成交额门槛。
- **决定**：2026-11-13 由使用者提出：“原来的规则可以或一下，或换手率达到 10 以上”。没有回测，效果只看之后的前向记录。

## 规则

清单所有分组的股票，满足下面**任意一条**就算过了门槛（V12 的两条不变，加第三条）：

1. 观察日成交额 ≥ 门槛（全市场近 20 日日均成交额的万分之 6，2026-11 约 10 亿）；
2. 近 5 个交易日里至少 2 天成交额 ≥ 门槛（一字涨停的日子算达标）；
3. **观察日换手率 ≥ 10%**（新加）。

- 换手率只看观察日当天（按使用者原话理解），之前某天换手高不算。
- 换手率缺失的股票不能靠第 3 条通过（不当作 0，也不当作达标），仍按前两条判断。
- 全市场成交额数据不足、门槛未知时，和 V12 一样不过滤，并在表头写明。
- 表头的门槛行写出“或观察日换手率≥10%”；被剔除的股票仍列在表头和 `summary.json`。

## 参数

| 参数 | 值 |
|---|---|
| 换手率下限 | 10%（观察日） |
| 其余 | 同 V12 |
