# 题材缺源与早期发酵展示诊断 V1

2026-10-10授权的报告修正，呈现版本`ACTIVE_MAINLINE_AND_EARLY_SIGNAL_DISPLAY_V3`，特征版本`THEME_COVERAGE_AND_PENDING_OBSERVATION_DIAGNOSTICS_V1`。旧run、原FSM、全部数值阈值和股票选择冻结；参数仍尚未验证，MARKET_EDGE=NOT_ESTABLISHED。

原始题材记录或已认证观察日题材行缺失时，报告必须突出“主线识别不可用，个股名单不能证明主线覆盖”。UNKNOWN不能呈现为无主线或弱题材，也不能用事后取得的当前成分补写旧盘前预测。

重点仍是有冻结合格候选交集、完整成分当日发酵/走强条件成立的题材。通过原两交易会话确认的列为“确认主线”；只有原候选条件PASS、处于EMERGING_PENDING/STRENGTHENING_PENDING的，另列“主线发酵观察，尚未确认”。不能为了早报而改成已确认。按既有阶段、精确扩张倍数、RS5、广度排序，没有新分数、经济阈值或行业排除。

发酵条件沿用原RS3，走强沿用原RS5；不能在展示层再给发酵附加RS5已知门槛。RS5未知仅影响排序中该轴的可比较性，未知值仍原样保存。

诊断保留全部与合格票相交的来源标签供内部核对，不能把所有PENDING标签自动发布为多条主线。面向用户的报告仍须限定经过独立当日主线证据核验的范围，归并同一交易方向的标签并保留各自来源，避免重复占位。早期观察与两日已确认、独立高位风险均分开说明，风险直接复制原生父事实。

缺20日基准或其他事实的合格题材另列数据缺口，不能按弱题材处理。报告应给出已到手源覆盖和所需窗口：当前扩张基准需T之前20会话，两日确认还需T-1自身的20会话基准；观察一个更早日期须向前补足其独立预热窗口。保留完整交易所日历，不把断档拼成连续确认。

诊断函数要求原生父结果和冻结选股两个独立验证能力；JSON自算hash或verified标志不能授权主题或名单。当前篮子回看显式保留捕获时钟、成分模式、选择偏差和历史主线资格未知。催化、龙头梯队、涨停/晋级与龙虎榜可作为各自有时间证据的研究维度，当前诊断不伪造其数值或给缺失游资信息加分。

供应商目录个数与成员原始字节核对，只能证明完整取得该供应商定义的篮子，不能证明经济题材成分完整、及时或每条标签业务相关。缺少独立主题事实核对时，taxonomy完整性保持UNKNOWN；没有进入该篮子的股票不能因此被认定不属于某题材。后续须把有当日公告/政策/复盘来源的实际交易聚集和容量篮子分开建证据，不能盲目合并多个成员列表并声称“全概念”。
