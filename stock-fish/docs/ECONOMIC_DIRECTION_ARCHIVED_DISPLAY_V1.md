# 经济方向归档展示 V1

`ECONOMIC_DIRECTION_ARCHIVED_DISPLAY_V1` 是薄封装中的显式只读交付入口。它读取已经保存的[经济方向解释](ECONOMIC_DIRECTION_EXPLANATION_V1.md)及其精确分组父附件，输出同一观察集合的完整文本、JSON 和文件清单。来源原件的认证与新附件生成仍属于原来的独立有界工作流；这个读取入口不重新选股、认证 selector、恢复来源权限或打开业务数据库。

从业务目录使用项目已核验的 Python 环境：

```sh
python scripts/codex_research.py economic-direction-display \
  --attachment SAVED_EXPLANATION_JSON \
  --grouped-parent EXACT_GROUPED_PARENT_JSON \
  --output NEW_PRIVATE_DIRECTORY
```

省略 `--as-of` 时采用实际 UTC 当前时刻。显式 `--as-of` 必须带时区；它控制资料可见性，不改变业务日期、原名单或任何保存时钟。参数代表本次核对的真实路径，产物留在私有研究目录；现有输出目录拒绝覆盖。

## 归档与完整显示

两个完整归档各自上限为 32MiB；这是派生附件读取边界，与生成端单个业务原件 8MiB 的边界分别登记。重复 JSON 键、非有限数值、读取时或渲染后的文件变化均拒绝。保存附件 hash 只是完整性检查，不能赋予来源权限。

读取器核对附件 schema/content hash、父文件完整 SHA/content hash、原 run/input/日期绑定、全部原分组、原选择顺序、每项全文和完整并集。原 V4 确认主线、发酵观察及活跃分歧三种角色保持。实际渲染使用的业务关系索引、经济方向选择索引、模型 fallback 索引、分组顺序和角色逐项绑定；仅保留一份完整行数组不足以证明最终文本不漏股。重算附件自 hash 不能绕过这些交叉检查。

解释仍分别显示有限已证业务关系子集与原子题材阶段。已证观察股的金额/广度不代表经济板块全集，不能由其金额给整体强度排名。来源节点计数冲突、非 A 原行、参股、项目阶段、非主营或未知关系保留。原选择、score 和 FOCUS 保持；`MARKET_EDGE=NOT_ESTABLISHED`。

## 显示时钟

原选择截止和原 native context 截止须与父附件完全相同。新的证据截止和实际生成时间不得早于已知父创建/情境时钟、全部已证业务关系及已计提供方节点的真实捕获时钟、可选保存报道的实际收到时间；显示时刻不得早于新截止或生成时刻。

完整校验之后，只有 `as-of` 覆盖附件实际可见时刻才显示。早于这一时刻返回 `NOT_YET_VISIBLE`，不输出候选、名单数量或市场数值。不能通过提前填写附件时钟暴露晚到资料。归档读取并不重新认证历史 PIT；晚到解释不回填旧报告。
