# 短周期强度研究 R1

`SHORT_HORIZON_STRENGTH_R1` 是独立研究策略；当前特征版本为 `SHORT_HORIZON_EXACT_V2`，说明修订为 `SHORT_HORIZON_STRENGTH_R1_SPEC_2`。此前 `SHORT_HORIZON_EXACT_V1` 的私有回算、身份与来源快照保留；旧 `STAGE_AWARE_MOMENTUM_V2`、五族公式及已有 run 保留。参数均为初始假设、尚未验证，`MARKET_EDGE=NOT_ESTABLISHED`。这里的候选仅是研究观察，正式 FOCUS 与 CORE_PASS 均为零。

## 三个独立阶段

- **STRONG_START**：当日收益至少 6%，RS1 至少 2 个百分点，成交额至少 1 亿元，成交额/前五个会话平均成交额至少 1.5；收盘超过此前五个会话最高收盘及 MA5、MA10；T−1 的五日收益不高于 12%；CLV 至少 0.7，或有效且有成交的正收益 RAW 平价 OHLC。它描述明显价格推进和交易活动扩张，称为启动，不把活动扩张称为价格加速。
- **STRONG_CONTINUATION**：成交额至少 5000 万元，五日收益至少 15% 或十日收益至少 25%；当日收益至少 5%、三日收益不为负、RS5 为正；CLV 至少 0.7，或合法正收益 RAW 平价 OHLC；收盘高于 MA20，MA20 不低于五个会话前。阶段已积累明显强度，不统一要求放量或换手，以保留缩量的强势价位路径。
- **FIRST_PULLBACK**：成交额至少 2 亿元，五日收益至少 20%、三日收益至少 5%；此前连续三个会话每日收益均为正，当日首次转为负收益，范围为 −8% 至 0%（不含 0）；收盘高于 MA20、MA20 不下降。它仅确认“连续三次正收益后第一次负收益”的窗口事实，不声称整个行情周期第一次回撤，也不声称已经修复。修复状态固定为 UNCONFIRMED。

所有公式使用原证据解析器在资料截止前实际可见的价格和父来源。收益、均线、突破均使用同一可比价格基准；当日形态使用 RAW OHLC 和 RAW 参考昨收。金额及比例用 Fraction 精确比较，展示四舍五入不得返回阈值判断。历史缺失、基准不一致、市场基准不完整或来源不可见时保持 UNKNOWN。

RS 的市场基准以观察日完整资格池为分母，包含目标证券。每个 peer 只有在对应收益窗口的全部会话（w+1 条记录）均满足原 PIT 解析器及完整父来源、VALID 质量、正可比收盘和非空一致可比基准时才贡献端点收益；合格 peer 的端点收益取简单等权均值。有效比例至少 60% 才有可用基准，低于 60% 或无有效 peer 时 RS 为 UNKNOWN。60% 沿用原市场基准定义，不是重新调整的名单参数。不同窗口分别检查，不把全 25 会话缺口设为统一阶段门槛。EXACT_V2 修复了 V1 市场 peer 仅验证收益端点的证据缺口，三阶段阈值、等权公式与覆盖门槛未改；缓存与覆盖元数据使用独立 R1 身份，旧 V2 逻辑不变。

## 输出与边界

三阶段用 OR 合并，但保留每一条条件、匹配阶段和反证。已知收盘限价下跌事件为 TRUE 时拒绝；未知事件保持 UNKNOWN，不能由约 10% 收益推断涨停。零日内区间保留 CLV=null，只报告 RAW 平价事实。市场、题材、资金和行为确认没有评估时明确为 UNKNOWN；可成交性为 UNCONFIRMED。

全资格池均保留。全池每行的完整诊断细节仅在 `items` 保存一次，`diagnostics_reference=items` 指明其位置，不再复制第二份全池行数组。研究匹配输出 WATCH 和 `research_selected=true`，已知不匹配输出 REJECTED，证据不足输出 UNKNOWN；没有数量截断和名单白名单。展示顺序仅为匹配状态、证券代码的稳定顺序，不是收益排名。没有统一换手、MA120/250 或旧 START/HIGH/momentum 门槛。

这些阈值由已知风格样本后的诊断形成，正反例及弱反弹描述切片都不是独立留出集。单次样本筛选只能验证实现和风格匹配，不能证明投资胜率、收益或市场有效性。另日使用冻结配置，不在新日自动根据名单调参；来源、公式或规则改变须登记新版本。
