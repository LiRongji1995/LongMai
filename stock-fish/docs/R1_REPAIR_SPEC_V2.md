# R1 研究合同修复 V2

本修订只改变报告、证据读写、执行配置接线及统计消费者，不改变原 R1 规则、12 组定义和 V2 默认路径。旧规格及报告保留原文；本文件说明新身份的差异。所有参数仍为尚未验证，MARKET_EDGE=NOT_ESTABLISHED。

## 可评价与漏斗

`R1_FACT_SELECTION_COVERAGE_V2` 根据实际有效依赖推导核心事实及完整选择可判定性。AND 中已知失败可短路；独立 setup OR 中任一完整通过可短路。未使用最终 WATCH/UNKNOWN 标签代替事实缺口。背景缺失单列；同一冻结输入新增可判定标为 CHANGED_REQUIRED_CONDITIONS_SAME_FROZEN_INPUT，不记新采集资料。

`common_selection_decidable_ids` 是查看收益前的共同支持；`common_core_fact_ids` 是核心支持。兼容 `common_evaluable_ids` 明确指前者，不表示执行收益完整。公共叶子按证券×信号日只计一次，setup 内公共引用不重复计；NOT_EVALUATED 和 COMMON_HARD_FAIL 保留。独立条件及交集允许重叠；终态分区互斥且与池大小核对。

候选存在、总体覆盖、选择可判定、必要/背景覆盖、执行完成及完整策略评价分别保存。未决资格或仍可能入选的未知证券禁止输出完整策略收益；已选子集保留在 observed_subset。合法零候选信号均值为 N/A，可评价账户按现金模型计算。

## 冻结执行与证据

`R1_EFFECTIVE_EXECUTION_SPEC_V2` 由配置校验后传入预算、数量、会话偏移、滑点与统计。默认仍为100万元、20%单股、40%已知题材、T+1/T+6、严格早于上海09:15、每边0/10/30bps，10bps主场景；20会话块、2000次、种子20261001、完整预登记族Holm。

`R1_ARCHIVED_EXECUTION_EVIDENCE_V2` 接受本地归档文件及 SourceReceipt。逐文件SHA256、行数、完整分页、行与回执成员关系及原四时钟必须一致；复用 EvidenceResolver、DailyBar、SecurityRecord。缺来源、错证券/日期、冲突修订、迟到证据均不升级。该验证是本地来源与内容核验，不等同供应商数字签名。

记录种类：CALENDAR、SECURITY、BAR、RULE、ORDER_LIMIT、ACTION_COVERAGE、COST。规则与费用必须提供明确可支持区间；引擎不会自动把当前规则延伸到任意历史。企业行动仅支持完整区间明确无行动证据；没有记录不等于无行动。行动账务不支持时保持缺口、未完成持仓及资本占用。

订单以截止前合法上限生成 PREDECLARED_SIMULATION_ORDER，整手数量不得依赖未来开盘；成交仅标 ASSUMED_OPEN_FILL。真实佣金不推断，成本只能采用显式预登记假设场景。真实 tape 的普通字典即使包含 verified=true 也不会获得执行能力。

## 输出与统计

`R1_SHARED_RESULT_V2` 使用按日期明细与内容哈希引用，共享背景与事实。manifest 在评价前冻结；result/completion 只在完整运行和源码身份再次核验后发布。未完成目录不能当作完整结果；拒绝覆盖。旧报告仍可只读汇总，新报告可按引用完整重建并校验。

按各组冻结父组比较，同时保留 R1_FULL−V2_CONTROL。估计目标区分声明总体重叠账户、双方有信号的条件收益、共同/新增可判定信号、各 setup 条件比较。无信号均值不补零；未知成交/退出不按完整结果事后筛除。账户日期使用原交易所 session_index，不对缺日重新编号；不足两个完整日期块、缺结果或退出延误达到块长均拒绝区间估计。完整比较族包含不可评价的比较，Holm 分母不缩小。结果不构成独立留出证明或自动晋升理由。

历史读取沿用真正只读 SQLite 入口，档案总规模与所需窗口分开。索引校验与实际消费价格字节校验分开声明。V2 仍保留整个当日总体及依赖窗口上下文；不是常数内存算法，不按股票小批独立排名。超时、输入/输出字节预算错误保留未完成目录，使用较小日期范围及新输出目录重试。

## 官方资料边界

本轮核对了[上交所2026交易规则](https://www.sse.com.cn/lawandrules/sselawsrules2025/fund/trading/c/c_20260424_10817739.shtml)、[深交所2026规则通知](https://investor.szse.cn/lawrules/rule/trade/t20260424_620190.html)及[财政部2023年第39号公告](https://m.mof.gov.cn/czxw/202308/t20230827_3904226.htm)。2026版交易规则从2026-07-06实施，不能覆盖更早日期。中国结算过户费的本轮官方检索未取得足以登记证券×日期执行证据的资料，因此没有新增真实税费适用区间。网页索引本身不替代输入归档的日期化证据，也不填永久有效截止。

## 有效规格与预算补充

manifest 同时保存基础有效规格及包含实际成本场景的 `effective_execution_specs`；账户返回实际规格与所选滑点的场景哈希。`--execution-spec` 只接受执行/统计字段，未知字段及规则/组变更提前拒绝，参数试验不改变默认配置文件。历史信号需要显式 `publication.mode=HISTORICAL_ASSUMPTION`、`assumed_published_at` 和资料可用时刻；发布时间不得早于实际信号 cutoff。没有已验证真实发布回执时不会标为真实前瞻发布。

共享对象以约4 MiB目标分片保存，长列表每256项建立可校验引用；索引与各分片及成员均核验。预算分别为输入JSON64 MiB、归档执行证据单文件8 MiB/总128 MiB、历史消费字节2 GiB/单输入300秒、历史读取期间进程峰值1 GiB、共享对象有效负载2 GiB。RSS 是进程高水位，不是缓存大小。高基数列表不截断，摘要样本会同时给出完整条数及引用。

非零统计的数学边界通过固定正/负差异样本验证；多日 CLI 另验证合法空仓账户与无信号 N/A 的分离。这两项都不说明策略盈利，也不把空仓账户零差异当成投资有效性。

研究入口对历史绑定输入跳过可选的全窗口预加载，继续调用原 V2 InstrumentBars 的8证券LRU；研究请求将压缩缓存预算设为64 MiB；所有价格访问、修订选择、事实原语及全总体排名保持原实现。原 V2 默认入口没有修改。同一历史 fixture 对原预加载路径与研究缓存路径的完整 V2 输出逐字段比较，不仅比较候选数。压缩缓存不足时可能重新解析证券窗口，读取计数如实累计，不宣称每条记录始终只解析一次。

历史输入在一份只读 SQLite 事务快照内完成 manifest、索引及消费行核验，按日释放；并发后续提交不能在同一输入评价中混入。manifest 在后验前显式登记比较对、8种估计目标和最少完整块数。
