# 原生流式题材研究 R1

2026-10-10本次工程授权新增显式研究执行版本`THEME_EVOLUTION_STREAMING_R1`和`THEME_CYCLE_STREAMING_R1`。不替换旧producer、默认策略、数据库或股票选择。沿用原题材FSM及关系研究的精确公式和初始未验证参数，MARKET_EDGE=NOT_ESTABLISHED；工程测试不能证明投资优势。

`SourceMarketStream`按原观察日交易所完整日历推进，每个可用会话仍从原始字节重建，核SHA、同日master、四板A股范围、交易状态、OHLC和实际可见时间。描述manifest只登记各日原panel摘要与来源，不授予价格权威。缺源留UNKNOWN，不压缩日历，不把历史下载当过去first_seen。

`SpoolingEvidenceResolver`继承原证据resolver全部guard，保留每一条allowed行的真实canonical记录，按32MiB段写私有NDJSON与行索引。去重、按行hash排序后的完整依赖摘要与原内存模式精确一致；封存后核每段/索引和每行SHA。禁止关闭row记录、覆盖已有目录或把审计journal当业务数据库。没有提高256MiB普通artifact读取限制、全局整数转换限制或舍入精确Fraction。

题材执行只保留当日市场panel、最多两日selected bar引用及每题材前60日feature状态；全部输出行与原批量模式同值。关系层每日剔除共同成分，以原市场补集及前60会话OLS计算当日留出残差；scope和新父结果各需可信原生能力验证。固定日历季度不能伪装情绪周期，当前basket回看不能伪装历史主线或合格机会全集。

独立TEST_FIXTURE验证批量/流式完整items、阶段、风险、source refs、依赖摘要及关系observations/intervals/OLS逐值一致，同时覆盖缺日、迟到、来源冲突、成员变化、非交易排除、篡改、资源对象释放和超长精确整数编码。真实来源认证、真实全年覆盖和多情绪周期投资验证须分别报告。运行预算由调用者显式传入，不能把轮询内存监控称为操作系统硬限制。

调用入口为`theme_evolution_streaming.run_theme_evolution_stream`及`theme_cycle_streaming.run_theme_cycle_streaming`，使用已有`MarketInput`和显式私有source-reader映射；不连接券商、不下单，不新增服务部署。
