# 主线与情绪周期复盘标准 V1

本标准对应用户在2026-10-10明确授权的持续策略修复与年内多轮复盘。它约束研究过程和证据验收，不改变默认主动核心、R2门槛或原题材FSM。任何新增预测规则另存配置、特征和实现版本，参数先标“尚未验证”，`MARKET_EDGE=NOT_ESTABLISHED`。相关实现见[题材演变](THEME_EVOLUTION_R1.md)、[原件流式研究](THEME_STREAMING_RESEARCH_R1.md)、[主线呈现V4](THEME_OBSERVATION_DIAGNOSTICS_V1.md)及[报道事件证据](THEME_EVENT_EVIDENCE_V1.md)。

## 范围与三层证据

用户清单和正式主线报告仅关注当日交易活跃、与冻结合格候选相交、并有独立当日主线依据的经济方向。同方向多个供应商标签归并，保留各自来源；全部PENDING标签不自动成为主线。非主线只在解释资金轮动确有必要时出现。

年内复盘分三层，不能相互替代：

1. 报道线索：政策、公司公告和不同原创媒体支持当时受关注的方向、命名核心股、报道梯队及分歧。先保留为待核验线索，不等同历史合格主线。
2. 原始业务事实：逐日认证RAW价格、成交额、换手定义、证券身份与风险资格、主题成员和限价事件。作业成功、transport完整或当前目录完整不等于这层完成。
3. 模型与投资验证：使用登记版本、合法当日输入和完整可追溯日历产生结果，再以独立情绪周期检验识别与后验。缺资格、未成熟、未运行和失败各自保留，缺收益不填零。

供应商题材成员完整仅说明该目录范围，不证明经济方向成员及时完整。今天的成员或候选回看只标`CURRENT_COHORT_BACKVIEW`，不能声称历史主线全覆盖。新闻提到证券且带代码也不能替代当日交易所身份、风险资格或可交易性。

## 多源互证与冲突

优先核政策及公司原始披露，再对照至少不同原创媒体家族的市场复盘，并以逐日量价和事件验证。家族数量是证据描述，尚未验证为预测门槛；两篇新闻不直接升级FOCUS。同稿转载、同上游通知或共用底层行情不计多份独立事实。记录原URL、原件SHA、实际请求/收件时钟、页面发布时间及精度、解析器版本和字段定位。

日期only发布时间用半开区间表达，不填精确午夜时刻。现在下载过去网页不证明当时已取得，网页也可能后来修订。历史报道用于事后复盘；未经真正旧可见性证明，不进入原盘前run。禁止用人工时间证明绕过后取得的新闻时钟。

以下情况保留冲突或未知，不自动调和：

- 沪深、沪深北、交易所四板A股等成交额范围不同，不混入同一动态分母。
- 涨停、触板、炸板、封板率须有同池、同时点定义。报道数字算术不一致或同稿数值冲突不猜测另一口径。
- 盘中触板、收盘封板、连续板和X天Y板分开。午间八板、收盘炸板止步七板可为时点路径，不能当必然矛盾或认证连续八板。
- Token等调用数量不当成交金额；涨价区间冲突且缺上游通知时保持未知。
- 更名前后名称不凭记忆连接证券；现今风险标签不倒填过去。

## 周期边界与阶段

固定季度、月份和任意两个报道日期都不是已认证情绪周期。每轮记录首次可见发酵、扩散或晋级、分歧、失败/退潮与可能再启动的日期和反证；起点之前已强标左删失，终点未见衰退或出清标右删失，中间缺日不自动连成持续周期。同题材的重新催化与不同波段分别核验。

保持事实、原数值阶段和报道解释分列。强度、活跃性、风险以及可交易性是不同轴。合法首日候选显示“发酵观察，尚未确认”；仍活跃且两日确认PASS的DIVERGENCE显示“活跃主线，出现分歧”，不隐藏也不重标走强。新闻梯队不能覆盖原FSM；热度也不能覆盖公司澄清、缩量锁板和高位失败。

策略审查至少检查：催化到量价的时间间隔、命名核心股到板块扩散、梯队晋级/失败、板块成交额的相对扩张与绝对变化、有效换手/可交易性、广度和集中度。还未实现或未认证的轴明确列出，不以形态已经识别代替。

## 资金关系

产业链互补不等于交易协同。剔除共享证券后分别看绝对金额变化和市场占比；占比此消彼长不证明资金绝对相互流出。再控制市场共同影响，报告样本数、窗口、残差可用性与区间。关系随阶段分别观察，不能用全期平均掩盖切换。

当前原生配对研究仅是描述统计。未认证历史主线资格或情绪边界时不能宣称多周期检验，不能把残差相关写成资金迁移、互害互利因果或投资优势。

## 信号及变化趋势

先登记可计算的事实轴，再验证是否有预测增量。每个序列保留业务日、实际资料截止、父来源SHA、成员模式、资格范围和定义版本。参与股票、上涨股票、符合选股规则的股票分别计数；当前供应商篮子不能冒充整个经济题材，成交额也不等于净流入。

| 事实轴 | 水平与变化 | 拟检验用途及反证 |
|---|---|---|
| 资金扩张 | 题材成交额、市场份额、相对前20日中位数；逐交易日增长与增速变化 | 区分随大盘放量与主动扩张；金额下降但份额上升不能当吸金增强 |
| 参与与承接 | 交易/上涨/规则合格股数、上涨广度、成交中位数、同定义换手分布、超过当日软参考的家数 | 看放量是否扩散到可交易候选；高额集中少数容量股与普遍扩散分开 |
| 集中及分化 | 前三股成交占比、调整HHI、龙头与中位股强弱、参与家数变化 | 资金扩张伴随广度下降和集中度上升是分歧候选，不直接判顶 |
| 相对市场 | 题材RS3/RS5及其变化、同窗明确指数收益、指数/市场广度及波动 | 区分逆市走强、顺市反弹及高波动；四板等权市场收益不叫上证指数收益 |
| 持续与梯队 | 连续可认证候选活跃交易日、催化龄、首发到扩散间隔、晋级/失败与修复时间 | 分别研究发酵、扩散、分歧延续与衰退；缺日中断，X天Y板不等于连续板 |
| 席位参与 | 同一已证一日/三日窗的买卖金额、净额、参与席位数、重合/新进入/撤离 | 研究接力还是集中撤离；摘要重复理由不叠加，席位标签不自动对应游资自然人 |
| 题材关系 | 去共享成分后的金额/份额变化、控制市场后的相关、带滞后关系 | 比较接力、挤占及共同走强；闭合份额与共用龙头产生的假负/正相关须剔除 |

变化按实际相邻交易日计算，不用日历间隔或未来资料补点。成员/价格基准变更须拆窗；金额增长要求合法正分母，缺基准为UNKNOWN。短期拐点至少保留前后水平、斜率及反证，不能将一个联合变化未经检验写成确定的顶/底。连续候选活跃天数只是来源状态持续时间，尚不等于完整情绪周期。

新增假设优先比较单轴与联合轴、原策略与加情境对照，检验识别提前量、误报、漏报、可成交性及后验回撤。跨周期依赖、重复股票与重叠窗口采用按周期分组的检验/不确定性估计；尝试的指标与窗口留账，避免大量挖掘后只挑最好结果。新的预测阈值、系数、概率校准及操作反馈均待独立样本验证。

项目反馈分两步：先向主线报告提供事实趋势、风险反证与缺数，保留原规则判定；有效增量经独立验证后再登记新情境配置，用于观察优先级、阶段参与条件或风险控制。不得在私有脚本另造名单，也不得先接新权重再把同一发现样本当检验。当前已完成两只来源主线篮子的四日真实趋势挖掘，属于事后描述研究，不是年度多周期预测规律。

## 迭代与验收

每次保留问题样本、对照失败及未知，登记通用修复假设、所用周期、改动版本和验证集。参与度等阶段规则不能为一个目标名字直接放宽；固定5%也不能仅因一例遗漏就声称有效或无效。

在一组周期发现或调参后，用不同、非重叠且具有真实资格的周期检验。训练/检验边界和评价指标先登记，隔离跨边界价格窗口与结果泄漏。D+1/3/5收益、可交易性、回撤、成本与同期未选/未知样本分别报告。至少三轮独立周期是本次初始验证目标，不是已经达到的结论；通过工程测试也不等于投资验证。

每天给完整清单及阶段/风险，周末汇总主线进展。无需用户逐轮审查；本任务范围内自主复核、修复和验证。普通后续日报仍不自动授权源码调参、提交、收费来源或运行服务切换。年度完成以逐轮证据与缺口表为准，不以新闻篇数、运行次数或当前篮子回看长度代替。
