# 研究数据边界

证券身份须包含交易所。日期化资格、业务会话、实际可见时间、完整父来源与 RAW/复权基准分别校验。缺字段、未知事件、日期外日历或冲突来源返回 UNKNOWN/Unavailable，不能补零、猜值或把不完整数据标为合法 EMPTY。

`yaogu` 中的 provider、capture、normalizer 和 source reader 保存原始回执、SHA、长度、实际首见时钟及来源范围。历史下载不能证明资料在过去已取得；输入和后验标签须使用各自截止时间。派生缓存只能缓存确定性事实，不能给普通 JSON 授予来源能力。

新计算按当前源码闭包和配置内容记录身份。历史 run/input、源引用、失败记录、认证时间不重写。只读封存查看验证本地封签和导出内容，明确 `source_reauthenticated_now=false`；完整来源认证仍要求原清单中的原件和原代码字节。

文件跨运行只核 SHA-256 和长度，不绑定设备号、inode、mtime/ctime。运行中的锁、事务、原子写和进程回收仍检查实际对象，规则见 [SELF_USE_FILE_INTEGRITY_V1](../docs/SELF_USE_FILE_INTEGRITY_V1.md)。

配置中的日期化交易所规则与当前来源完整性仍须逐次校验，不能从静态文档推断最新数据就绪。系统不连接券商或下单，研究匹配不代表可成交性或投资有效性。
